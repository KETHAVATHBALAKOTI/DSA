# 🚀 Java DSA Implementation & Patterns

A structured collection of Data Structures and Algorithms implemented in Java. This repository serves as a foundational resource for mastering computer science fundamentals, tackling complex problem-solving patterns, and preparing for advanced software engineering assessments (like the Infosys Specialist Programmer rounds).

## 📚 Topics Covered

### 1. Array Patterns & Manipulation
*   Dynamic sliding window techniques
*   Manual array sorting algorithms (without built-in `Arrays.sort()` methods)
*   In-place element manipulation

### 2. String Processing
*   Advanced string manipulation logic
*   String Constant Pool memory architecture concepts applied to algorithmic efficiency
*   `StringBuffer` and `StringBuilder` optimizations

### 3. Mathematical & Number Theory Algorithms
*   Prime factorization and Smith numbers
*   Digit manipulation and mathematical constraints

### 4. Core Data Structures
*   Implementation of foundational structures using Java's Collections Framework
*   Custom data structure design

## 🛠️ Tech Stack & Environment
*   **Language:** Java (JDK 21+)
*   **Concepts:** Core Java, Exception Handling, Wrapper Classes, Functional Interfaces & Lambda Expressions
*   **IDE Setup:** Optimized for Visual Studio Code and IntelliJ IDEA

## 💡 How to Use This Repository
Each algorithmic pattern is separated into its own package with heavily commented code to explain the *why* behind the logic, making it ideal for both self-study and mentoring demonstrations. 

1. Clone the repository: `git clone https://github.com/yourusername/your-repo-name.git`
2. Open the project in VS Code or IntelliJ.
3. Run individual `.java` files to see console outputs and test edge cases.
